# Astrel 本地优先个人博客工作台

Astrel 是一个本地优先的个人博客与学习管理桌面应用。它把 Markdown 写作、任务打卡、自由照片墙、番茄钟、考研学习台、单词复习、成就系统和二次元风格个性化界面整合在一起。

项目当前以本地使用为主，同时为后续改造成公开联网博客预留了结构。

## 功能特点

- Markdown 写作：支持实时预览、标签、分类、草稿、归档和纯阅读模式。
- 打卡清单：支持列表视图、月视图、日程视图、日期跳转和逾期任务显示。
- 任务管理：支持子任务、右键菜单、优先级、分类、科目绑定和完成记录。
- 自由照片墙：支持多个照片墙、上传、拖动、缩放、旋转、图层调整、重命名和删除。
- 番茄钟与正计时：支持暂停、重置、结束记录、自定义学习科目和学习时间统计。
- 考研学习台：支持倒计时、每日启动页、复盘、周报、学习热力图和成就徽章。
- 单词复习：支持词库导入、记忆曲线复习计划、熟悉度总览和重置功能。
- 个性化外观：支持头像裁剪、背景图、背景音乐、透明度、高斯模糊、正文字号和魔法光标效果。
- 桌面应用：支持 Electron 打包为 Windows 便携版 exe。
- 本地保存：通过本地服务和 Electron 用户数据目录保存个人数据。

## 隐私说明

这个公开仓库不会包含你的个人运行数据。

以下内容已通过 `.gitignore` 排除：

- `data/`：文章、任务、专注记录、考研记录、设置等本地数据。
- `uploads/`：上传的背景图、头像、音乐和照片墙图片。
- `dist/`：Electron 打包产物。
- `node_modules/`：依赖目录。
- `*.log`：运行日志。

公开截图、发布版本或分享备份前，请再次确认其中没有个人笔记、学习记录、头像、背景图、音乐文件等隐私内容。

## 环境要求

- Node.js 18 或更新版本。
- npm。
- 当前打包脚本主要面向 Windows。

## 本地运行

安装依赖：

```bash
npm install
```

以本地网页方式运行：

```bash
npm start
```

然后打开：

```text
http://127.0.0.1:8766/
```

以 Electron 桌面应用方式运行：

```bash
npm run electron
```

打包 Windows 便携版：

```bash
npm run pack:win
```

打包结果会生成在 `dist/` 目录中。

## 数据保存方式

当前应用采用本地优先的数据策略：

- 网页模式通过 `/api/state` 和 `/api/upload` 保存本地数据。
- Electron 模式会把数据保存到 Electron 的 `userData` 目录，而不是源码仓库。

因此，源码可以安全公开，个人数据仍然保留在本机。

## 后续联网改造方向

项目已经把应用逻辑和数据访问层做了初步分离，后续可以逐步替换为联网版本：

- 用户登录与权限管理。
- 数据库保存文章、任务、学习记录和设置。
- 对象存储保存图片、音乐等上传资源。
- 文章公开 / 私密可见性控制。
- 桌面端与网页端同步。
- 部署到云平台，形成真正的公开博客。

具体阶段计划见 `联网公开博客改造步骤.md`。
